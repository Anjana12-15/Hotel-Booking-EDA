# Hotel Booking Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a Hotel Booking Demand dataset using Python. The goal is to understand hotel booking patterns, cancellation rates, room pricing, and monthly booking trends.

## Dataset
The dataset contains hotel booking information for City Hotels and Resort Hotels, including booking status, lead time, average daily rate, customer details, and arrival dates.

Dataset source: [Hotel Booking Demand Dataset on Kaggle](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Analysis Performed
1. Dataset structure and data types
2. Missing value analysis
3. Numerical summary statistics
4. Categorical feature analysis
5. Booking cancellation status
6. Booking lead time distribution
7. Average Daily Rate (ADR) by hotel type
8. Cancellation rate by hotel type
9. Monthly booking trends
10. Correlation heatmap of numerical features

## Key Findings
- Non-cancelled bookings were more common than cancelled bookings.
- City Hotel had a higher median Average Daily Rate than Resort Hotel.
- City Hotel had a higher cancellation rate than Resort Hotel.
- August recorded the highest number of bookings, while January recorded the lowest.
- The correlation heatmap helped identify relationships between numerical features.

## Conclusion
This project demonstrates how Python libraries can be used to explore, analyse, and visualize hotel booking data. The findings can help identify booking patterns and provide insights that may support hotel business decisions.
